# Linux Security Journey
A study journey about Linux and security, documented by concepts.


## Overview
The OverTheWire Bandit is a great study game for those people who are interested in learning about commands in Linux and for those who want to study cybersecurity, aiming to build a solid base. I completed the 34 levels of the game, and I can say it is such a great exercise to start in this area, because it made me think hard, especially when the levels weren't that easy. I organized all the writeups by concepts, not by level.

## Writeups
All five writeups are available for reading and cover the concepts learned in all 34 levels:
- [Basics](overthewire-bandit/01-basics.md)
- [Data Hunting](overthewire-bandit/02-data-hunting.md)

## Note
This repository follows a basic rule: I never expose any password or solution to a level, I only talk about the concepts and the commands.
